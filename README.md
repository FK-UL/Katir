# Katir
Katir is a simple python program made to easily and quickly look up Kattis problems to see if they have been reserved.
For use with the Programming 1 course offered by the Faculty of Mathematics and Physics in the University of Ljubljana.

## How to use:
1. Download the .zip of the code or clone the repository.

2. Make sure all the files remain in the same folder
3. Run 'katir.py'
